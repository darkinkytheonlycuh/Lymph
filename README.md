# Lymph

Lymph is a Gorilla Tag modding suite: mod menu, injector, executor, mod manager, spoofer, unbanner, and auto-updater.

## Projects
- `Lymph Menu/` - In-game mod menu DLL (PC + VR), auto-updater, cosmetic give, unbanning, spoofer, account gen, explorer, Lymph Extras mods.
- `Lymph Injector/` - Standalone injector + mod manager + executor (merged), auto-updater.
- `Lymph Executor/` - Standalone code executor.
- `Lymph Site/` - Vercel site + update server (auto-updater endpoints).

## Versioning
Starting version: V 1.0.0. Auto-updater checks `https://lymph-site.vercel.app/api/version`.
